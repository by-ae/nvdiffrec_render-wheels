Install

Pip keeps a wheel when its Python, ABI, and platform tags match this machine, then installs the newest version. It does not look at which PyTorch build is already installed. On linux_x86_64 the newest matching file is 0.0.1+cu130torch29 (CUDA 13.0, PyTorch 2.9.1, cu130-torch291). On win_amd64 the newest matching file is 0.0.1+cu128torch29 (CUDA 12.8, PyTorch 2.9.1, cu128-torch291). Open another configuration above for a different build.

pip install nvdiffrec_render --find-links https://by-ae.github.io/nvdiffrec_render-wheels/
